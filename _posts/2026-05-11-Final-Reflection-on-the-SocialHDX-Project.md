The SocialHDX project was the largest and most complex web development project I have worked on so far. Throughout the semester, I gained experience working with database design, Razor Pages, Entity Framework Core, frontend usability, and collaborative software development.

The project focused on creating a social prescribing platform that allows faculty and staff to connect students with campus events and support systems. The application also allows users to track prescriptions, student cases, and follow-up notes through a centralized dashboard system.

My primary contributions focused on backend development, database implementation, workflow organization, and usability improvements.

---

## My role in the project

During the project, I spent most of my time working on:

- Database schema planning
- Entity relationships
- Razor Pages implementation
- CRUD functionality
- Dashboard organization
- Navigation improvements
- Workflow integration
- UI cleanup and usability

I worked heavily on connecting the entities throughout the system so the application functioned as a connected workflow instead of isolated pages.

Some of the main systems I helped implement included:

- Students
- Prescribers
- Campus Events
- Prescriptions
- Student Cases
- Student Case Notes

I also spent a large amount of time improving the usability and consistency of the backend application so it would be easier to navigate during demonstrations and presentations.

---

## Challenges during the project

One of the biggest challenges during the project was balancing functionality, organization, and usability all at the same time.

As the database became larger and more connected, even small changes could affect many different parts of the application.

Some common problems included:

- Database migration issues
- Foreign key relationship problems
- Build errors after model updates
- Navigation inconsistencies
- Debugging Razor Page connections
- Organizing workflows between entities

Another challenge was the overall scope of the project. There were many possible features we wanted to implement, but time limitations required focusing on creating a strong working prototype instead of attempting every possible feature.

---

## Frontend and backend integration

One important lesson I learned during this project was how frontend and backend systems connect together in a real web application.

At the beginning of development, many frontend pages existed as static HTML prototypes. As the project progressed, these ideas were gradually integrated into the Razor Pages backend application so the final system could support real database functionality.

This helped me better understand how:

- frontend layouts,
- backend logic,
- database systems,
- and workflows

all interact together in a larger application.

By the end of development, the application had evolved into a more unified system with:

- connected database workflows,
- dashboard-driven management,
- event recommendation systems,
- and consistent navigation and styling.

---

## What I learned

This project helped me become more confident with:

- ASP.NET Razor Pages
- Entity Framework Core
- Database relationships
- CRUD operations
- Backend debugging
- Workflow organization
- UI usability improvements
- GitHub collaboration

Compared to earlier labs and assignments, this project felt much closer to a real-world application because it involved many connected systems instead of isolated examples.

I also gained a better understanding of how important organization and usability are in larger projects. A system can function correctly technically while still being difficult for users to navigate, so balancing both areas became an important part of development.

---

## Future improvements

Although the prototype is functional, there are still several improvements that could expand the system further in the future.

Some ideas for future development include:

- Connecting prescriptions directly to student cases
- Implementing a real authentication system
- Adding automatic email reminders
- Expanding event filtering and recommendations
- Improving analytics and reporting systems
- Enhancing mobile responsiveness

These improvements would help make the application feel even closer to a production-ready system.

---

## Final thoughts

Overall, the SocialHDX project was one of the most valuable programming experiences I have had so far.

The project combined:

- database design,
- backend development,
- frontend usability,
- teamwork,
- and long-term project organization

into a single application.

Even though there were many challenges throughout development, the project helped me better understand how larger full-stack web applications are built and maintained.
